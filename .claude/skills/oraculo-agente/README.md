# Skill `oraculo-agente`

Receta de Claude Code para crear automatizaciones y agentes de IA de Oráculo con un mismo método: ficha aprobada, conectores (Composio), código con pruebas, auditoría obligatoria y prueba en local antes de encender.

## Cómo se usa
En Claude Code, dentro de este repositorio, escribe algo como «quiero automatizar…», «quiero un agente que…» o `/oraculo-agente`. Claude sigue el protocolo de `SKILL.md`.

## Para usarla en otros repositorios de Oráculo
Copia esta carpeta a `.claude/skills/oraculo-agente/` del otro repositorio, o a `~/.claude/skills/oraculo-agente/` para tenerla en todos tus proyectos.

## Créditos
La idea parte de [`crear-agente`](https://github.com/santmun/crear-agente) de Santiago Muñoz / Horizontes IA (licencia MIT). Esta versión se reescribió para Oráculo: Claude como cerebro, Composio para conectar apps, auditoría obligatoria y las reglas de `CLAUDE.md`.
